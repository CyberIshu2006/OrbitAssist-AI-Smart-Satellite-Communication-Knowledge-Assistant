# OrbitAssist AI – Smart Satellite Communication Knowledge Assistant

## Overview
OrbitAssist AI is an AI-powered Smart Satellite Communication Knowledge Assistant designed to simplify complex satellite communication concepts through an interactive and user-friendly interface.

## Features
- Interactive AI-based question answering
- Satellite communication knowledge retrieval
- Beginner-friendly explanations
- Covers frequency bands, satellite orbits, communication techniques, and applications
- Responsive web interface

## Technology Stack
